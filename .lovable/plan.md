# ToeicSpace Brand Logo Redesign

## Direction
Build the selected “Artistic oyster serif” identity using the locked Pearl Sea palette, an elegant serif wordmark, and the official Oysteic shell artwork.

## Implementation
- Keep one horizontal logo structure for light and dark modes; switch only its semantic gradient colors.
- Place the official shell mark beside an italic “Toeic” and refined “Space” wordmark.
- Add a restrained pearl highlight, signature stroke, and small brand line without a background container.
- Preserve clarity at header and mobile sizes, with only a subtle hover shimmer.
- Export the finished lockup as a transparent PNG after visual verification.

## Quality checks
- Verify light and dark contrast.
- Verify desktop and mobile sizing without collisions.
- Confirm the header and theme toggle remain fully usable.
